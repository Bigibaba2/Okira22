# Security concerns

For a suspected security issue in this public repository, email [armin@bigiraden.com](mailto:armin@bigiraden.com) with the affected file or commit, a concise description, and minimal non-sensitive reproduction information.

Do not put credentials, private keys, personal data or confidential customer information into public issues. An initial message should not contain a full private data dump.

This page is a contact route, not a bug-bounty program, safe-harbor agreement or authorization to test infrastructure. Do not test third-party systems, customer environments or domains merely because they are mentioned here. No response-time commitment, supported-release schedule or monetary reward is promised by this page.

The runtime is under development. Historical release and installer files are not evidence of a current security review. No production deployment is required for the founder-led pilot.
