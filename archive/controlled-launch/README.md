# Controlled-launch archive

This directory preserves the earlier public installer for reference. It is not the
current installation or pilot onboarding path.

- `install.sh.txt` contains the original installer bytes without edits.
- Original Git blob: `4b16eee0f154cd20a30c9e77f0c04a3696ff238f`.
- Source commit preserved in history: `4d9a5025eccfb1f9a49b75a74b513fd7ec95adf5`.

The `.txt` extension signals archival content; it is not a sandbox. Running this
historical content as a shell script would still invoke its original download and
installation behavior. Do not execute it as part of the current pilot.

The GitHub release and its assets have not been deleted or edited by this archival
change. Existing installations are not affected.
